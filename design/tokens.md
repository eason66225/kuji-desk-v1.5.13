# Kuji Desk · Tkinter 設計 token

T-002 規格以 UI v1.5.34、相容服務 v1.5.30 為基線。沿用 Windows 原生選單、系統對話框、`tk` 元件及 `ttk` 的深色 `clam`。下文的「提案」為供製作A整合的呈現調整。尺寸為 Tk 配置用 px，字級為 pt；高 DPI 以實際字型量測和可見範圍驗收。

## T-009 · 綠／紅底按鈕

維持 `ON_ACCENT='#10151c'`。現有 Microsoft JhengHei UI 10 pt 粗體以一般文字的 4.5:1 為門檻。綠、紅底均達標，紅底餘量約 0.30:1，因此維持現有紅底亮度，hover 也沿用同一配色。比值以 sRGB 相對亮度計算，顯示到小數第二位，判定用未四捨五入原值。這是色值複核，Windows 字型平滑與 DPI 的實際觀感待目視確認。[WCAG 2.2 SC 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

| 底色 | `ON_ACCENT` | 白字 `#FFFFFF` |
|---|---:|---:|
| 綠 `#38A169` | **5.65:1** | 3.25:1 |
| 紅 `#E05252` | **4.80:1** | 3.82:1 |
| DC Webhook 深藍 `#2B3D52` | 1.65:1 | **11.10:1** |

### 適用範圍

| 按鈕 | 啟用時的配色 |
|---|---|
| 頂欄「開啟背景服務／關閉背景服務」 | 開啟為綠底、關閉為紅底，兩者皆用 `ON_ACCENT`。 |
| 主設定「一起開始監看」「停止全部監看」 | 開始為綠底、停止為紅底，兩者皆用 `ON_ACCENT`。 |
| A／B／C 帳號卡「開始監看／停止監看」 | 每張卡各一顆切換鈕。開始為綠底、停止為紅底，兩者皆用 `ON_ACCENT`。 |
| DC Webhook 設定對話框「儲存設定」 | 綠底，使用 `ON_ACCENT`。 |
| 頂欄「🔔 DC Webhook 設定」 | 深藍 `#2B3D52` 底配白字 `#FFFFFF`，normal 和 hover 相同。 |
| 其他按鈕 | 深藍次要鈕沿用 `#283648`／`#EEF3F8`，例如「重新啟動服務」「執行紀錄」。萊姆主按鈕沿用 `#D7F896`／`#16220D`，例如「知道了」。兩類皆排除 `ON_ACCENT`。 |

表格前四列共七個實體按鈕。以用途和當下底色判斷，`primary=True` 本身不足以套用 `ON_ACCENT`。

### 互動與停用

| 狀態 | Tkinter 規格 |
|---|---|
| Normal／hover | 保留現行 `tk.Button` 的 `activebackground`／`activeforeground`，跟隨當前綠／紅底與 `ON_ACCENT`。啟用時以手形游標回饋，無需新增 hover 色。切換開始／停止或開啟／關閉時同步更新 normal 和 active 的色對。 |
| Pressed／focus | 維持文字色對，按下回饋與鍵盤焦點沿用下方元件狀態規格。 |
| Disabled（提案） | `state='disabled'`，底色 `#283648`，`disabledforeground='#A0AEC0'`，對比 **5.44:1**，游標改為一般箭頭。滑入仍維持停用外觀。按鈕保留用途文字，旁邊的狀態說明用可讀文字提示原因。 |

現行帳號卡監看鈕在已有帳號資料時可因忙碌或無可用動作而停用，但仍配置綠／紅底。共用的停用灰字 `#6B7786` 在這兩個底色上僅 **1.40:1／1.19:1**。停用元件可豁免 4.5:1，此處仍應讓文字可讀，並用中性底、一般游標和原生停用狀態表明不可操作。帳號卡的停用配色須涵蓋缺少帳號資料的提前返回路徑，避免留住前次的綠／紅底。恢復啟用時依當下動作還原 normal／active 色對和手形游標。共用停用樣式只需針對這組按鈕覆寫。

製作A 整合後，於 Windows 100%／150% 縮放以目視核對 10 pt 紅底文字、滑入／滑出、停用後滑入及恢復，並確認頂欄 DC Webhook 快捷鈕仍是深藍底白字。本輪只核對來源與色值。

## 字級與間距

| 字級 | 用途 |
|---|---|
| 9 | 更新來源與時間、次要輔助訊息 |
| 10 | 欄位標籤、輸入、按鈕、表頭、表格、卡片摘要 |
| 11 常規／13 粗體 | 一般說明／人工驗證提示標題 |
| 16 粗體 | 帳號卡標題 |
| 18／25 粗體 | 尚無順位時的文字／實際順位與已就緒 |
| 22／36 粗體 | 主視窗標題／剩餘總數 |

主字型為 Microsoft JhengHei UI，網址輸入沿用 Segoe UI。提案：對現用 Tk 預設字型的數字欄位和勾選項指定 10 pt 主字型，使表單對齊。密集畫面先換行或重排。9 pt 用於附註，主要狀態與操作不縮小。

| 間距／尺寸 | 配置 |
|---|---|
| 2／3／4 | 表單密集項目、卡片各列垂直間距 3、操作格外距 2×3 |
| 6／8／10／12 | 小群組；按鈕間距 8、卡片間距 10、表單垂直內距 12 |
| 14／16／20／24 | 卡片水平內距 14、表單水平內距 16、對話框內距 20–24、主視窗左右留白 24 |
| 按鈕、輸入 | 按鈕 `padx=10`、`pady=7`；主要輸入 `ipady=7` |
| 表格、捲軸 | 表列基準高度 26；垂直捲軸寬 11；字型超出列高時隨字型增加列高 |

## 元件狀態

| 元件 | 規格 |
|---|---|
| Treeview.Heading | `normal` 用 configure，`disabled`、`pressed`、`active`、`focus` 全部明確 map。五態底色、bordercolor、lightcolor、darkcolor 均為 `#202C3A`，文字 `#A0AEC0`，flat、無立體邊。表頭在各態皆維持深底。 |
| Treeview 資料列 | 一般使用條紋和一般文字。零的賞別列用零值文字配表格底；選取覆蓋條紋與零值配色，使用選取底與一般文字，數字 0 仍可見。 |
| 互動焦點（提案） | Tab／Shift+Tab 按閱讀順序，僅可操作或可檢閱的元件入列。用 2 px `#8BB9FF` 外框，在深色周邊顯示焦點；如 `clam` 樣式元素無法可靠呈現，在外層框繪製且預留尺寸。Treeview 焦點畫在表格外框。按鈕 Space 啟用，只有安全的確認操作可設為 Enter 預設。 |
| 按鈕／勾選項（提案） | 正常顯示用途文字。Hover 維持正常配色並以指標提示可點，按下以邊框或內凹輪廓回饋。勾選狀態保留勾記，停用以 widget state 阻止輸入。送出中同一動作停用並顯示等待原因，避免重送。 |
| Entry／唯讀下拉／分頁（提案） | 一般欄位使用輸入底與一般文字，選取底沿用表格選取；唯讀下拉可選清單項但不可任意輸入，選單和箭頭維持深色。分頁用面板底，選中頁用表頭底及一般文字，非當前頁用次要文字；焦點依外框規格。 |
| 正常、等待、錯誤、空值（提案） | 一般文字交代目前狀態。等待用次要文字和明確等待原因；需本人介入用橘色及下一步提示；確定錯誤用紅色及可採取的動作。無資料用 `—` 配文字說明。讀取失敗且留有資料時顯示上次讀取時間及失敗提示。各態皆可只用文字辨識。 |
